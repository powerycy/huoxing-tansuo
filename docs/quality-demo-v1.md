# High / Ultra 演示画质 V1

「高 · Mac」（High）用于 Mac 演示，「极致 · 4070S」（Ultra）作为 RTX 4070 Super
演示档。名称表示使用目标，不是显卡识别结果或帧率承诺。本轮已经在 Mac 浏览器
检查两档场景，以及暂停时 Ultra → High 的切换；任务和花海进度保留，检查过程中
未观察到 GPU 警告。4070 Super 尚未实测。

另已在浏览器确认：High 保存后刷新仍被选中；运行中 Ultra → High 保留任务时间、
电量与导航；High 的夜间已供电基地预览配合车辆近光能正常显示。

## 档位与设备路径

参数以 `src/core/quality.js` 为准；显卡能力仍会限制实际各向异性、主光阴影尺寸和
MSAA 采样数。

| 项目 | High · 高 · Mac | Ultra · 极致 · 4070S |
|---|---:|---:|
| 内部渲染像素上限 | 2,400,000 | 4,200,000 |
| 目标 DPR 范围，仍受像素上限约束 | 1–2 | 1.15–2 |
| 地形网格参数：单层宽度 / 层数 / 近景单元 | 160 / 9 / 0.16 米 | 192 / 9 / 0.13 米 |
| 主光阴影贴图 | 2048² | 4096² |
| 车辆主车灯阴影 | 1024² | 2048² |
| 基地维护泛光阴影 | 1536² | 2048² |
| 近景局部灯的地形高度采样 | 4 步 | 8 步 |
| 地形主光遮挡图 / 步数 | 1024² / 76 | 1536² / 96 |
| 车辙 / 挖掘贴图 | 4096² / 4096² | 4096² / 4096² |
| 贴图各向异性目标 | 8× | 16× |
| 扬尘粒子预算 | 2200 | 3200 |

像素预算限制的是浏览器内部绘制缓冲区。实际尺寸还取决于窗口、系统 DPR 和档位；
大窗口可以使有效 DPR 低于表中的目标下限。Ultra 在 1080p 窗口可增加内部采样，
但不能据此称为固定 1440p、4K 或稳定 60 FPS。当前关闭运行时自动分辨率调节，
可在设置中手动切换档位，并查看实际渲染尺寸。

Mac 保留防闪烁路径：8-bit LDR 目标、FXAA、关闭 MSAA 和后期 Bloom。
即使手动选 Ultra 也不改变这条路径；灯具和萤火虫自身的柔光仍可显示，辉光偏好
仍会保存。非 Apple 设备在支持 HDR 渲染目标时，High/Ultra 使用半浮点 HDR，
MSAA 为设备支持范围内最高 4×，再经过 FXAA。Bloom 需要该设备路径、对应档位
以及用户开启设置共同满足；缺少 HDR 支持时回退到 LDR、无 MSAA/Bloom。

## 启动与保存

启动顺序为：有效的 `?quality=low|medium|high|ultra` → 已保存的有效档位 →
设备默认值。桌面 Mac 在没有有效请求和保存值时默认 High；其他设备依据逻辑
核心数、可用内存提示和粗指针输入选择 Low/Medium/High，不会自动猜测 4070 Super
或默认启用 Ultra。无效的 query 值会继续检查保存值和默认值。

在设置面板手动改档后，选择写入当前存档命名空间，同时从当前地址移除 `quality`
参数；刷新会遵循手动选择。之后重新打开带明确 `quality` 参数的链接，会再次以
该链接指定的档位启动。

切档重建后期管线时会保留当前曝光、演出黑边与月光眩光等镜头值，只为新尺寸和
抗锯齿预算更新相关参数，避免暂停时画面突然恢复默认曝光或失去黑边。

带 `event-preview`、`station-preview`、`charger-preview` 或 `time-preview` 的页面
使用独立 `.preview` 任务和设置存储，不覆盖正常任务。只有 `quality` 参数的页面
仍使用正常任务存储；它只是指定启动画质。

## 已落到场景的变化

地面复用现有扫描贴图，以粗糙度和视角参与漫反射、高光及局部灯照明；
扫描法线保留多尺度细节，远处通过过滤控制细碎高光。没有新增 8K 资产。

车辆沿用实际 4K GLB 中的 ARM、法线、AO 与标识贴图。车漆、金属和橡胶继续读取
同一图集中的不同表面信息；车漆涂层降低强度并按亮色非金属区域遮罩，朝上的
表面积聚少量火星尘。基地保留 Halley 和附属舱原有粗糙度、金属度贴图，取消整体
压低金属度的处理。着陆舱按实际材质名称区分金色隔热箔、银色结构、黑色隔热层和
涂漆件，箔面增加轻微、随距离淡出的褶皱法线。四类扫描岩石保留法线和粗糙度，
只为已核实的 ARM 贴图恢复红通道 AO；保留原 UV 通道和颜色空间。

主光阴影采用贴图像素对齐的构图，减轻跟车移动引起的阴影滑动。
切换仍开启阴影的档位时，也会释放尺寸不符的旧车灯/基地灯目标，再按新预算分配。
基地断电、终端恢复、暖窗亮起和外部灯具恢复的时间与位置保持现有逻辑。

High/Ultra 为主车灯和基地维护泛光照到的近景地面增加 4/8 步高度场遮挡近似。
它复用宏观/远景地形及挖掘高度，限制灯到受光点距离不超过 96 米，并在距相机
100–160 米范围逐渐淡出；厘米级细节不参与。这只影响自定义地面接收的局部光，
不等于完整地形投影网格，也不能保证岩壁向车辆、建筑投下完整局部灯阴影。
有限采样仍可能漏过狭窄山脊，不能宣称所有山体穿光已解决。

四档画质默认均使用原光栅渲染。另有默认关闭的「实验光追 · 接触遮蔽」，
只对近景基地/车身做真实三角形求交，见 [实验说明](experimental-contact-rays.md)。
没有加入路径追踪、实时全局光照（GI）、光追反射、SSR 或 TAA。
现有 WebGL2、扫描资产与稳定环境反射继续承担主要画面表现。

## 花海实时切换

设置修改会同步更新五类预算：程序草、VAT 玫瑰、远景程序花、升空花瓣和萤火虫。
切换保留既有首花位置、伴生花圈、引导花带、粒子种子、生长时钟、巨月进度和镜头
状态；不重新启动世界或重新下载玫瑰资产。异步玫瑰资源若在切换后完成，会采用
最新档位。

| 显示预算 | High | Ultra |
|---|---:|---:|
| 程序草基础轴采样数，各 LOD 按比例使用 | 768 | 1024 |
| VAT 玫瑰每个 LOD 的实例预算 | 720 | 1100 |
| 远景程序花预算 | 3000 | 4500 |
| 升空花瓣预算 | 924 | 1344 |
| 萤火虫容量 | 320 | 420 |

预算不代表这些对象同一帧全部可见；仍受距离、LOD、生长和渐隐控制。

## 启动与检查入口

在项目目录执行 `npm start`，服务端口为 5176。打开页面后从菜单进入预览；
`event-preview=1` 会在进入后启动花海演出。以下链接可直接复现对应场景：

- [正常任务 · High](http://localhost:5176/?quality=high)
- [正常任务 · Ultra](http://localhost:5176/?quality=ultra)
- [夜间已供电基地 · High](http://localhost:5176/?quality=high&station-preview=powered&time-preview=night)
- [夜间已供电基地 · Ultra](http://localhost:5176/?quality=ultra&station-preview=powered&time-preview=night)
- [完整花海演出 · High](http://localhost:5176/?quality=high&event-preview=1&time-preview=night)
- [完整花海演出 · Ultra](http://localhost:5176/?quality=ultra&event-preview=1&time-preview=night)

4070 Super 建议先用 2560 × 1440 窗口检查 Ultra，记录浏览器、实际绘制尺寸、
HDR/MSAA 状态以及基地、近景玫瑰和远景花海的帧耗时，再决定演示窗口与档位。
目前没有该显卡的帧率或显存实测结果。

## 自动验证与边界

新增四个 CPU 检查脚本：

```sh
node tools/check-quality-profiles.mjs
node tools/check-model-materials.mjs
node tools/check-terrain-pbr.mjs
node tools/check-vegetation-quality.mjs
```

它们分别覆盖档位优先级、像素与设备能力回退、实际后期管线重建时的 DPR/曝光/黑边
保持及旧资源释放；实际 GLTF 材质解析、纹理语义和阴影
资源释放；地面光照公式、遮挡采样和 16 槽采样器预算；五类植被/粒子切换、异步资源
完成顺序及演出状态保留。CPU 检查不能替代 GPU 编译、实景阴影判断或目标机器性能
测量。原有光影、增力、花海镜头和场景集成回归命令见
[光影与演出记录](scene-lighting-cinematic-v1.md)。
