# 最终事件：二维化撤离

本次新增独立终章，不修改前半段基地恢复、花海、正常车辆设置和 T 单击充电。

## 可玩流程

1. 在孤立中继站停车，按 E 对接通信货物。中继亮起，给车辆一次满电、修复底盘，并启用持续超载供能。
2. 进入约 22 秒的可跳过观测演出：中塔充能 → 靠近扫描岩层 → 岩层压成地面油画 → 图景沿固定交界向上收走 → 拉远仰视横贯山谷的不规则画幕。淡入宽银幕黑边，HUD 隐藏；不闪白、不加全屏噪点。
3. 用约 2.8 秒平滑交还原驾驶镜头，再给完整 8 秒自由撤离准备。演出及镜头归位期间车辆驻停，追击、捕获、耗电均不推进。空格或字幕区按钮提前交还镜头，仍保留归位保护及 8 秒准备。
4. 二维化从中继后方 65 米开始，以固定 7.5 米/秒沿母港方向推进。不会跟随车的位置瞬移、拐弯或动态加速。演出中仅视觉边界从后方 110 米推进到 65 米；与正式追击连续衔接。
5. 沿金色地面标记和地图路线返航。普通超载目标 20 米/秒，按住 Shift 为 40 米/秒；松开恢复普通超载，空格刹车。转弯需要主动减速。
6. 母港 100 米内提前提示减速。进入距离母港中心 10.5 米范围，速度低于 0.75 米/秒，按住 E 1.6 秒传输。仅有效按住时暂停追击；松手或驶离则恢复。
7. 传输完成进入正式结束画面，车辆和追击停止。内容为记录进入地球上行队列，而非即时到达地球。已二维化的世界保留在结算背景，不突然恢复成立体。
8. 被追上或底盘彻底损坏：显示失败，可从中继充电区满电重试。保留此前基地、花海和货物对接状态，不触发原有“损坏后直接传送母港”救援。

## 公平性和存档

- Esc、菜单、照片模式暂停追击。逃生期间失焦/切换标签自动暂停。
- 低帧率下追击与车辆使用相同的最大 50 毫秒模拟时间，后台停留不会累计追击距离。
- 超载只影响终章，不改驾驶性能/牵引力设置的保存值；信号延迟在终章暂时改为本地直控。
- 逃生存档 v2 保存演出进度及归位保护。有效 v1 追赶存档继续原进度，不重播镜头；缺失或无效事件存档从受保护的演出开始，已完成存档保持已完成。
- 逃生读档还原位置、姿态、速度、车轮转速及车灯，避免高速撤离时读档把车强行停下而被追上。
- 终章不需要再停下来补电；正常三个充电区和 T 功能不变。
- 预览链接使用独立 preview 存档，不清除正式进度。

## 视觉实现边界

这是 WebGL 的实时顶点变形与局部油画着色近似，并非物理降维或 RTX 光追。最新美术目标见 `concepts/dimensional-starry-upfeed-reference.png`（概念图，不是游戏截图）。删除旧版 13.5° 斜面方案；采用“先压平、再输送”的路径：15 米压缩带 → 34 米贴地段 → 6 米半径的连续直角转折 → 竖直输送段。承接图景的立面没有独立几何边框，不发生整张画旋转，也没有卷筒。

变形使用真实地形、扫描岩石、建筑与草花几何；法向余厚为 1.2%，并用少量斜投影保留建筑侧面。后方源几何沿转折上移，动画不是预渲染视频。立面上缘通过固定世界坐标的多尺度高低轮廓裁切形成参差笔触，两侧没有额外矩形遮罩。

油画表面 v4 不再使用程序化等高线/同心圆。二维区域直接映射完整的梵高《星月夜》式厚涂油画素材 `assets/textures/events/dimensional-starry-oil.png`，粗短笔触、蓝金色块和大旋涡来自图像本身。源几何和少量量化明暗保留建筑轮廓，二维区域不再依赖原 PBR 高光来表现色彩；车及未受影响的区域仍按原材质渲染。素材由图像生成工具制作，不是梵高原作扫描；见同目录制作记录。

整幅油画锚定源世界坐标，约每 320 米映射一个完整构图，使用连续镜像寻址和显式纹理梯度过滤；没有随时间随机变化的全屏效果。色彩、深度阴影共享变形及上缘裁切；clipmap 环带保留额外层间偏移，降低压平后重叠闪烁的风险。

近景复用现有摄影测量岩石组成观察岩层，使用同一模型贯穿完整、压缩、贴地与上收阶段。镜头从月光侧观察，使用四元数连续转向、地形避让及局部阴影焦点；12–20 秒逐渐拉远仰视画幕，最后留出 2 秒观察。归位时阴影焦点一同返回车辆。被输送到远处的源地形不再被误判为相机脚下的障碍。灯具一起投影并逐渐失去立体照明，然后同步地面的灯光锥。前方驾驶地形和碰撞保持原样。

不额外占用地形采样器，不改变 Mac 的稳定 LDR 路径、不重建 PMREM，不强开 Bloom/MSAA。折叠期间暂不合成实验光追接触遮蔽，因为它的 BVH 仍是未变形几何；用户的设置开关和资源保留。回菜单或重新开局后恢复正常渲染。

v4 将原 `uGeology` 槽升级为两层 RGBA8 纹理数组：第 0 层逐字节保留地质数据，第 1 层装入油画。地形仍为 16 个采样器，不增加第 17 个；2048² 两层含 mip 约 42.7 MiB，相比原地质贴图增加约 21.3 MiB。所有材质共享这一数组，四档画质重建不重复装载。地质保持线性数据，油画单独执行 sRGB 解码。启动时等待素材完成；装载失败时保留原色而不显示程序化条纹。

并非所有自定义粒子和远景都参与完整降维；薄面观感仍属于可玩首版，有进一步美术迭代空间。4070 Super 帧率尚需在目标 Windows 机器实测。

## 本地入口

- 完整流程：`http://localhost:5176/`

- 直接回看后方追击：`http://localhost:5176/?escape-preview=chase&time-preview=night`（预警已跳过，需要及时离开）
- 母港结束检查：`http://localhost:5176/?escape-preview=home&time-preview=night`
- 开发集成测试：`http://localhost:5176/tools/escape-playtest.html`。测试按钮使用真实场景、车辆物理、碰撞、逐帧任务逻辑和人工输入替身；不是性能基准。
- 真实画面逐段检查：`http://localhost:5176/tools/dimensional-cinematic-preview.html`。可定格 6 秒接触、11 秒地面油画、16.5 秒向上收走、21.8 秒天地画幕，也可连续播放与跳过；仅使用预览存档。

## 验证

`node tools/check-dimensional-escape.mjs`：状态切换、固定追击、暂停、有效 E 保护与释放、重试、保存/加载、结束不可重入、预览存档隔离、超载持续供能、避免传送救援、真实六轮物理在 30/60/120 Hz 下的平地及 30°/50°均匀坡、刹停和空中重力不变。

`node tools/check-dimensional-cinematic.mjs`：真实 CameraRig 与状态机在 30/60/120 Hz 下的连续性、22 秒演出与 2.8 秒归位、三种驾驶镜头恢复、42°/82°视野设置、地形避让、早晚跳过、暂停、演出中及归位中读档、旧演出时长迁移、菜单初始镜头修正、控制与 LOD 接入检查。

`node tools/check-dimensional-fold.mjs`：原扫描岩石复用、地面压缩先于向上输送、固定弯道连续性、已有及新画质 clipmap 材质挂接、实际草/花着色器接入、深度裁切钩子、灯光投影和恢复、演出与追赶连续衔接、完成时保留油画世界。这是 CPU/源码回归，不替代 GPU 编译和画面检查。

理想平地约 19.83 / 39.82 米/秒；全速刹停约 48 米，50°理想坡约 53 米。实际坑洼、急转弯与碰撞会降低速度；这些数字不保证所有地形都能全速通过。

前一版浏览器驾驶基线：保守自动驾驶沿 47 个避障导航点到达母港，52 秒完成终章，最终距离母港中心 9.5 米，最低底盘 98.1%，最高约 53.7 km/h。该数字不含本次油画演出，也不等同于玩家全程 Shift 或 4070S 的帧率测试。旧斜面版曾检查真实 Mac 高画质画面；本次油画版本的视觉验收单独记录，不能沿用旧截图或旧验证结论。

原 Windows ZIP 不自动重打；本次修改在项目目录内，旧压缩包不包含本终章。
