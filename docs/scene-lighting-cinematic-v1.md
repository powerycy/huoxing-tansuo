## 花海演出

基地恢复供电后：20 秒巨月升起 → 12 秒草生长 → 16 秒第一朵花 →
22 秒拉远花海 → 4 秒停留 → 约 1.2 秒交还原镜头，总计约 75 秒。
首花实际舒展覆盖近 12 秒，不只是延长开放前后的等待。镜头位移跟随
各阶段进度同步放慢。巨月从山脊附近起步，去掉约 8 秒不可见的地平线下行程；
淡入与 1.9 秒入场运镜同时发生，月面不透明度在第 2 秒约 76%，第 3 秒约 100%。
根据基地实景山脊提高起点，月顶在开场约 2 秒达到 16° 仰角，避免继续被山挡住。
巨月保留单次 smoothstep，峰值仰角速度约 1.88°/秒，比原 28 秒方案还低。
V4 生长存档保留阶段进度；V4–V6 升月存档迁移到 V7 时保留其旧起点与实际
仰角，不跳动。新开场使用新起点；旧存档继续升起的剩余时间相应缩短。

- 月亮先升起，随后保持；首花焦点取自实际实例和 VAT 花瓣数据。
- 草长出后，草尖附近逐渐出现少量浅金色萤火虫；出生位置跟随相同的
  基地生长波，避开道路中央。约 0.5–1.8 米低空缓慢游动，连续柔光，
  不同步闪烁。随花海扩大，到凋零阶段逐渐消失，初始荒地和残留阶段不显示。
- 空格只退出镜头，世界中的生长继续。Esc 冻结任务时间和镜头。
- 临时隐藏 HUD，显示小幅说明；不显示全屏任务卡，不新增屏闪或镜头震动。
- 镜头接管期间驻停车辆，不刨坑、不扣灯光/驾驶电量，仍可充电。
- 还镜头保留原模式、角度和距离；读档不强迫重看。
- 花带在交还控制后继续指引中继站，到达前不会因演出计时而消失。

## 光影与基地

- 修正全场主光被车辆所在点遮挡一起调暗的问题；标准材质局部读取地形遮挡图。
- 地形实时引用方向光与局部灯的阴影矩阵，避免上一帧矩阵与当帧纹理错位。
- 车灯/基地灯的地面光池与实际灯共享位置、方向和锥角，接收模型的投影。
- 基地暖窗对齐实际模型窗框，供电按终端、窗灯、入口泛光和常亮顶部识别灯展开。
- 事件不再覆盖基地灯强度。未恢复前灯光全灭，恢复后不被花海压暗。
- 暗面反射使用加载期的稳定环境，运行期仅改变强度，不重建 PMREM。
- Mac 保留稳定 8-bit 渲染目标、关闭 MSAA/Bloom 的保护；修正辉光设置绕过保护的问题。
- 地形合并 VS/FS 活跃 sampler 共 16 个，复用扫描法线作第二尺度采样。
- 地面光照实际使用扫描粗糙度、视角和法线；车灯、基地泛光与主光沿用相同表面响应。
- 车辆保留原 4K 图集的车漆/金属/橡胶信息，减弱全表面涂层并按车漆区域遮罩；
  基地取消整体金属度压低，着陆舱区分隔热箔、结构金属与绝缘层，扫描岩石保留
  法线和粗糙度细节。复用已有资产和经核实的 ARM 通道，不新增 8K 贴图。

High/Ultra 现为主车灯和基地维护泛光照到的近景地面增加 4/8 步高度场遮挡，
与模型投影相乘；它是有限距离、有限采样的地面受光近似，不等于完整地形投影网格。
厘米级细节与狭窄山脊仍有遗漏风险，也没有让山体完整参与车辆、建筑接收的局部灯
阴影，不能声称所有山体穿光已解决。未加入光线追踪、路径追踪、实时全局光照、
SSR 或 TAA。Mac 两档均保留 LDR + FXAA 保护，Ultra 不会强开 MSAA/Bloom；
支持相应能力的非 Apple 设备可启用 HDR 和最高 4× MSAA。

High · Mac / Ultra · 4070S 的完整参数、保存规则、实时植被预算与测试链接见
[演示画质记录](quality-demo-v1.md)。本轮 Mac 浏览器已检查两档场景和暂停时
Ultra → High 切换，任务及花海进度保留，未观察到 GPU 警告；4070 Super 尚未实测。
切档重建后期管线还保留当前曝光和演出黑边；已有实际后期管线重建、DPR 与旧资源
释放的 CPU 回归覆盖。浏览器另确认 High 保存刷新仍选中，运行中切到 High 不改变
任务时间、电量和导航，夜间已供电基地配合车辆近光可正常显示。

## 增力

按住 Shift + 前进/倒车启用；松键、刹车、失焦、暂停和演出时取消。
低速轮端扭矩上限为原来的 2.8 倍、抓地上限 1.65 倍，极速包络提高 38%。
至少三轮接地时增加沿接触坡面的爬坡助力，施加在质心以减少抬头；
约 55–70° 逐渐衰减，离地没有额外推进。普通驾驶、重力和悬挂不变。
5–12% 电量平滑降低增力，5% 以下只保留原基础动力；额外固定耗电最多
0.045 个百分点/秒，电机负载仍按现有规则计费。

真实六轮 CPU 求解器的理想坡面测试：平地稳定速度 8.04 → 11.14 米/秒；
55° 从静止正向或倒车均可持续约 4.58 米/秒爬升。另验证平地连续驶入
55° 圆滑坡面与 30/60/120Hz 一致性。仍不保证垂直崖壁或巨石卡位能通过。

萤火虫 LOW/MEDIUM/HIGH/ULTRA 分别预分配 120/210/320/420 个地表光点，
视野内仅显示附近已生长区域。一个 Points 绘制，无额外纹理、逐粒光源或
逐帧地形计算；独立柔光不依赖 Bloom，不改变既有 16 槽地形纹理预算。
