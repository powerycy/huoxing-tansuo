# Sam 步行 V3 · 独立预览

2026-09-05。只用于 `character-preview.html`；未接入正式游戏。

## 动作来源与边界

- 参考用户提供的 `jwbi2Y_kvws` 的 Walk 段落（1:51 起），没有从视频提取或宣称复制原版动作数据。
- 动作底稿为现有 `Walking-Male-Standard-InPlace.fbx`，在 Sam 原生绑定上重烘焙。
- 当前为平地持续步行：未加入启停、转弯、坡地脚部 IK 或失衡动作。
- 原始 `.blend` 与旧版 `sam-porter-walk-v2.glb` 保留不动。

## 本次修正

1. 清理旧动画时保留 rig 的 drivers。原先 `animation_data_clear()` 会连同 IK/FK、手指与约束驱动一起删除。
2. 手臂按源动作的上臂/前臂方向驱动原生 FK，脚部通过原生 IK 与逐帧靴底测量确定高度。
3. 步行周期 1.3 秒；保留骨盆/胸腔的反向运动，较小幅度前倾。取消浏览器叠加的骨骼纠正与整个人上下校正。
4. 脚跟接触、全掌支撑、后脚掌抬起、摆腿是连续循环；地面后退速度匹配支撑期脚速。
5. 货物几何重新按实际包围盒居中，顶箱横放。使用 `PropertyBinding.sanitizeNodeName` 查找背部骨骼，避免含点的 Blender 名称在 GLTFLoader 中找不到，导致货架留在世界坐标。
6. 保留 10 个必要面部形态通道与自然眨眼/轻微表情。
7. 增加正侧面、斜后侧、四个阶段按钮和进度条，供人工核对。
