## 正式流程

中继交付完成 → 驻停锁镜头 / 车辆超载充能 → 蓝光升空 → 仰望油画星空 → 镜头转向地裂 → 归还驾驶 → 撤离至母港并停车按住 E → 上传记录 / 追击结束。

时间使用游戏模拟时钟，不是墙钟；低帧率会拉长实际播放时间：

- 0–4.8 秒：中塔建立镜头，约 1.2 秒开始汇聚蓝光，光柱向上延伸。
- 4.8–11 秒：镜头缓慢抬起；6 秒开始天空渐显。
- 11–17 秒：观看天空中的蓝白笔触和金色星团；两个旋涡以不同方向和速度流动，地平线不转动。
- 17–26 秒：先看远处山脊下沉，再看断层、落石和尘墙逼近；18.2 / 21.5 / 24.3 秒安排三次短促的震动与岩层撕裂声，不使用持续剧烈晃动。
- 约 2.8 秒归位：仍然锁驾驶、冻结追击。
- 交还驾驶后完整保留 8 秒撤离准备；之后地裂前沿按 7.5 米/秒推进。

Shift 沿用现有超载动力，约 40 米/秒的 CPU 目标速度，不改变重力。返航指示继续用真实地形/碰撞上的路径规划。仅到达母港并未完成：需要停车、按住 E 完成交互；有效母港交互期间受保护，松开或开走后追击继续。

## 渲染与边界

- 天空是相机周围的球形天空层和多深度实例化笔触，不是立在地面的矩形画。
- 复用已生成的原创厚涂油画素材 `assets/textures/events/dimensional-starry-oil.png`（1254×1254），不是从该视频导出的贴图，也不是对视频的逐像素复刻。
- Low / Medium / High / Ultra 分别绘制 8000 / 13000 / 19000 / 26000 个短笔触实例；每档都包含蓝白旋涡和金色星团。
- 光柱为真实中塔位置向上的多层几何体，附一个局部蓝色点光源；不强开 Bloom/HDR，不引入自动曝光闪光。
- 地裂通过地形着色器裁出开口，并绘制岩壁和深沟底面。主地形不增加采样器；断面复用扫描岩石纹理。
- 危险线后方的岩层按不同延迟分块下沉（当前深度约 4–14 米），扫描岩石及标准材质设施同步移动，阴影深度跟随。自定义植被着色器尚未做同样的变形，不属于全场景破坏模拟。
- 尘墙与落石位于追击前沿后方，不随机封锁前方道路；Low / Medium / High / Ultra 尘雾实例预算为 90 / 160 / 280 / 420，落石为 40 / 70 / 120 / 180。它们是实例化视觉效果，不是独立刚体碰撞。
- 裂缝当前是预设的蜿蜒横向断层，不是任意可破坏地形、全场景刚体地震或实时地质模拟。
- 裂缝只在失败线之后张开，CPU 驾驶高度保持不变；车辆会先被崩塌带判定追上，不会因物理/画面不同突然掉进洞。裂缝不随机封死前方返航路线。
- 演出时镜头小幅震动，驾驶时更弱；没有屏幕滚转、闪白、闪黑或全屏油画滤镜。震动和粒子使用事件时钟，暂停冻结，地震声音暂停时淡出。
- 每帧先移除上帧震动偏移，避免镜头漂移。短促冲击声在暂停或结束时停止；跳过演出不会补播全部冲击声。
- 地震期间暂停实验性接触光追通道，避免其静态场景结构与动态下沉地表错位；设置选择保留，未新增 RTX 硬件光追。
- 母港成功后追击、震动、扬尘停止，蓝光与异常天空约 4 个模拟秒内退去；裂缝留下静态痕迹。重开/重试会重置效果。
- 当前是 WebGL2 常规渲染。没有新增光追反射、全局光照或 RTX 硬件光追；4070S 帧率尚未实测。

## 地震表现修整 · 2026-09-12

- 用连续连接、不同深度和启动延迟的岩层替换整片地面的波浪式位移。裂缝分段张开，部分岩段保留连接，不再整条同时切开；CPU 与 GLSL 使用相同的确定性公式。
- 扬尘复用项目已有的 `assets/textures/collapse-dust/impact-flipbook.png`，25 帧插值。分为贴地扩散和向上扬起两层，降低发白感；每团烟尘从固定世界位置出生，不跟着追击线滑动。素材加载失败时保留简单烟雾回退。
- 碎石保持尺寸不变，抛出后沿重力曲线下落，接近地表或裂缝底时淡出。取消原来沿前沿游动的一组点状碎屑。
- 尘云按视锥过滤，再按质量预算选取，预算边缘渐隐；透明实例按视空间深度排序，靠近镜头的烟雾也会淡出。实例预算未上调，不以更多粒子掩盖问题。
- 地震段镜头留在中塔同一侧，分别观看远处山脊和较近断层，避开上一段录制中建筑横穿镜头的路径。
- 保持 26 秒演出、约 2.8 秒镜头归还、8 秒撤离准备及追击速度不变；不修改重力、车辆、充电和母港交互，也不增加闪黑、闪白或自动曝光切换。

新增检查：`node tools/check-starfall-field.mjs`（下沉单调性、位移范围、分段裂缝和安全边界）、`node tools/check-seismic-particles.mjs`（固定出生位置、暂停/定位重建、图集帧范围及抛物线）。

`check-starfall-event.mjs` 另覆盖真实地形上 20 秒、25.5 秒及追逐阶段的四档粒子预算、视空间排序、暂停和定位重建、结束清理与碎石淡出接线。以上检查以及原有驾驶、地形 PBR、场景接线回归均通过；Mac 浏览器的 20 秒、25.5 秒镜头图集已加载，预览诊断为 0 个着色器错误。

当前仍是着色器地形变形与双面烟尘片，不是真实流体烟尘、完整岩体断裂或独立刚体破坏。此轮不代表已在 4070S 上做性能验收，未重新录制或打包 ZIP。
